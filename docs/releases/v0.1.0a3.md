# Pitwall 0.1.0a3

This alpha makes personal serving the default way to use Pitwall: with only a RunPod credential,
`pitwall serve` launches an open-weight model on a pod with a self-termination deadline and
registers it as a route a coding agent can dispatch to. It is the first release published from the
public repository, whose history starts at a single commit. Like 0.1.0a2, it is a GitHub-first
release: Python distributions are attached to this release and the five service images are
published to GHCR. PyPI publication stays deferred.

## Highlights

- Personal-first serving without a database: `pitwall setup`, `serve`, `status`, and `stop`. Each
  pod carries an in-pod deadline that terminates it at its TTL, and `serve` refuses before launch
  when a price cap, CUDA floor, or startup budget cannot be met.
- One console script, `pitwall`; `serve-model` is now `serve`, and bare `pitwall` opens the
  console.
- A packaged model catalogue (`models list`, `show`, `fit`) with hardware-fit verdicts, vLLM,
  SGLang, and llama.cpp launch shapes, and warm-volume support.
- The free-tier gateway routes each provider to its own upstream through a route table, behind the
  existing budget gate, guardrails, and kill switch.
- The reconciler escalates an exhausted monthly budget to the kill switch.
- `pitwall doctor` reports installation readiness, and `pitwall mcp install` registers the MCP
  server with Claude Code, Codex, or OpenCode.
- Services refuse to start on an invalid setting, naming the variable and never its value.

The [changelog](../../CHANGELOG.md) lists every change.

## Important limitations

- This is pre-1.0 alpha software; breaking changes can occur under the documented
  [compatibility policy](../compatibility.md).
- Pitwall does not ship a GPU worker image. Operators supply the image or existing RunPod endpoint
  that performs inference.
- RunPod carries live evidence for this release. Vast.ai, Together, and Lambda Cloud adapters are
  code-complete without a live countersign; see the [support matrix](../support-matrix.md).
- No keyless free pool served anonymous callers in the 2026-09-23 benchmark; free routing needs
  pools you hold keys for.
- Deployment is self-hosted. Operators remain responsible for infrastructure, provider
  credentials, workload data, model and image provenance, and spend.

## Installation and verification

Install the CLI from a checkout with `uv tool install --python 3.14.7 .`, or download the wheel or
source archive and `SHA256SUMS` from this release. The container images use the following
namespace:

`ghcr.io/buckeyes22/pitwall/<service>:v0.1.0a3`

Prefer immutable image digests in deployed configurations. Verify downloaded artifacts against
`SHA256SUMS` and the GitHub attestations before use.

Please report vulnerabilities privately according to the [security policy](../../SECURITY.md).
Use GitHub Discussions for support and general questions.
