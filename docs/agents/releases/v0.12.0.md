# Pitwall Agent Routing 0.12.0

Pitwall Agent Routing 0.12.0 makes the orchestrator ↔ subagent channel event-driven and extends
managed dispatch to Pi workflows and Qwen Code. It is the first Agent Routing release published
from the public repository. The release uses the namespaced tag `agent-routing/v0.12.0`; broker
`v*` tags, gateway `gateway/v*` tags, and service images remain separate.

## Highlights

- Managed parent tools (`dispatch_and_wait`, `answer_and_wait`, `wait_dispatch`,
  `steer_and_wait`) return a child's questions, defaults, and results as events, so an
  orchestrator answers or steers without polling. A Claude launch guard blocks external launches
  outside managed dispatch.
- Durable workflows dispatch Pi tasks; providers without workflow support are rejected at
  validation.
- `setup mcp` registers `pitwall-channel` for Qwen Code (`~/.qwen/settings.json`, honouring
  `QWEN_CODE_HOME`), so `qwen` routes run as managed interactive dispatches.

## Fixes

- Workflows now answer asks from children on the live (tier-1) channel. Before, those asks were never
  policy-answered or escalated to the operator and ran out to their defaults.
- The policy answerer gives reasoning models room to think: it allows the route's output limit
  (default 1,024 tokens) instead of 64.
- `routes probe` and endpoint discovery send a `pitwall-agent-routing/1` user agent; RunPod's
  proxy had rejected urllib's default agent, so every RunPod route probed as `unauthorized`.
- `doctor` no longer reports a false `WARN` on an installed Grok Build CLI.

## Compatibility and migration

Ledger paths, environment variable names, the `SHIM-DONE` sentinel, and persisted record schemas
are unchanged. Update a durable source install with the bootstrap command for this tag, then run
`claude plugin marketplace update pitwall`.

## Release assets

The GitHub prerelease contains a wheel, sdist, `SHA256SUMS`, installed-wheel SPDX JSON, and GitHub
build attestation. Both Python artifact forms are built twice, inspected with explicit allowlists,
and exercised outside the checkout on Python 3.14.7 before publication.
