# Pitwall Agent Routing 0.10.0

Pitwall Agent Routing 0.10.0 is the first release from the Pitwall monorepo. It remains an
independently installable, MIT-licensed Python component with no runtime dependencies. The release
uses the namespaced tag `agent-routing/v0.10.0`; broker `v*` tags and service images remain
separate.

## Highlights

- Python 3.14 is the single supported minor, with 3.14.7 used for managed validation.
- The wheel and sdist provide `pitwall-agent-routing`, the compatibility `pitwall-agent-routing` command,
  packaged registry/config/schema resources, artifact-mode workflows, and loopback receiver
  behavior without a source checkout.
- Full Pitwall source installs provide the 13 provider shims, `route-shim.sh`, Claude Code, Codex,
  and GitHub Copilot CLI plugin packages through repository-root marketplaces.
- Runtime registry validation is separated from clone-integrity validation, so packaged dispatch
  and doctor work without source-only plugin, prompt, tool, or reference trees.
- Route schema coverage now includes shared endpoints, Pitwall auto-registration, per-route limits,
  and structural fixtures shared with runtime validation.
- Agent Routing uses separate scoped Pitwall API, subscription, and receiver credentials while
  retaining documented legacy fallbacks.
- Scheduler recursion and receiver service generation share a verified artifact/source execution
  descriptor and never rediscover an arbitrary checkout.

## Compatibility and migration

The `SHIM-DONE` sentinel, `pitwall-agent-routing` command, `model_routing` import, plugin/marketplace IDs,
record schema versions, and documented legacy environment names remain available. The source
repository, release tag namespace, durable payload layout, root marketplace locations, and schema
`$id` values change. Persisted schemaVersion-1 records require no rewrite.

Read the
[migration guide](../../operator/agents-migration.md) before
updating a durable source install. Do not repurpose a legacy standalone development checkout as the
new Pitwall payload.

## Release assets

The GitHub prerelease contains a wheel, sdist, `SHA256SUMS`, installed-wheel SPDX JSON, and GitHub
build attestation. Agent Routing 0.10.0 publishes no image or PyPI artifact. Both Python artifact
forms are built twice, inspected with explicit allowlists, and exercised outside the checkout on
Python 3.14.7 before publication.
